# Maurice for Android — releases

Signed builds of the Maurice Android app, published here so that
[Obtainium](https://github.com/ImranR98/Obtainium) can offer each new version.
The app is useless without a Maurice household to connect to.

Add this repository's URL in Obtainium:
`https://github.com/ckemmler/maurice-android-releases`

Every APK is signed with the same key (certificate SHA-256
`08:B9:A2:58:83:9E:E5:16:96:79:F9:0A:C7:4F:01:81:46:B2:86:A5:BB:7C:70:46:57:6A:55:83:52:91:B7:4A`):
an update installs over the previous version and keeps your data.
